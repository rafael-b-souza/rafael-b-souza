### 🚀 Featured Projects

- **[soccer-ball-detector](https://github.com/rafael-b-souza/soccer-ball-detector)**  
  End-to-end computer vision pipeline combining **YOLO11**, adaptive preprocessing, dynamic ROI tracking, and **Genetic Algorithm (DEAP)** parameter optimization for soccer ball tracking. Includes the academic research paper in `docs/`.

- **[microservicos-filme](https://github.com/rafael-b-souza/microservicos-filme)**  
  Multi-module **Spring Boot (Java 17)** microservices architecture featuring unified **Spring Cloud Gateway** routing, integrated OpenAPI 3 / Swagger documentation aggregation, and automated Hurl integration tests.

- **[ln-gateway](https://github.com/rafael-b-souza/ln-gateway)**  
  API access and authentication gateway featuring **Ed25519** single-use cryptographic challenges and prepaid API metering settled directly over the **Bitcoin Lightning Network** with transactional idempotency.

- **[ai-hardware-detector](https://github.com/rafael-b-souza/ai-hardware-detector)**  
  Android native **C++ / NDK** probe assessing local hardware acceleration capabilities (NPU, GPU, CPU) and benchmarking on-device LLM inference via **llama.cpp**.

- **[AISlicingAssistant](https://github.com/rafael-b-souza/AISlicingAssistant)**  
  Ultimaker Cura plugin integrating vision models to recommend print slicing parameters and inspect 3D toolpaths automatically.

- **[satsai](https://github.com/rafael-b-souza/satsai)**  
  Pay-per-prompt chat interface integrated with the Bitcoin Lightning Network via LNbits for instant, streaming paywall settlement.

- **[chainreaction](https://github.com/rafael-b-souza/chainreaction)**  
  Classic desktop Chain Reaction game in Java with Swing UI, tournament benchmarking driver, and pluggable AI architecture.
